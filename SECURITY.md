# Security Policy

## Supported Versions

Only the latest release of Nexus Voice Station receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Nexus Voice Station, please **do not open a public issue**. Instead, follow these steps:

1. Send an email or open a private GitHub security advisory through the repository's [Security Advisories](https://github.com/mevhatem/Nexus-Voice-Station/security/advisories) tab.
2. Provide a clear description of the vulnerability, including:
   - Steps to reproduce
   - Potential impact
   - Any proof of concept (PoC) code or scenarios
3. We will acknowledge receipt of your report within 48 hours and work with you to address and verify the fix prior to public disclosure.

Thank you for helping keep Nexus Voice Station safe and secure!
